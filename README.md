## Getting Started

Aplicación desarrollada con Flutter

## Qué hace la app

- Listado de personajes.
- Búsqueda por nombre.
- Pantalla de detalle de cada personaje.
- Estados de UI como loading, success, error y empty.

## API

Base: `https://rickandmortyapi.com/api`

## Probar

```bash
flutter pub get
flutter run
```
